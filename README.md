## 📂 Projetos em Destaque

### 🤖 01 — Monitor Vagas TI | Diego Tech

**Sistema automatizado de monitoramento de oportunidades de emprego na área de Tecnologia da Informação.**

**O problema**

Acompanhar diariamente diferentes portais de emprego exige tempo e verificações manuais frequentes. Isso pode fazer com que oportunidades sejam identificadas com atraso.

**A solução**

Desenvolvi uma aplicação em Python capaz de consultar portais de emprego, identificar oportunidades relacionadas à área de TI e enviar notificações automaticamente para o Telegram.

O sistema funciona na nuvem, sem depender de um computador ligado.

**Principais funcionalidades**

- Monitoramento automatizado de oportunidades de TI.
- Consulta aos portais Gupy e 2via.
- Verificações programadas a cada 15 minutos.
- Filtragem de oportunidades relacionadas à tecnologia.
- Notificações automáticas pelo Telegram.
- Controle de histórico para evitar mensagens duplicadas.
- Persistência dos dados entre execuções.
- Limitação de notificações para evitar excesso de mensagens.
- Execução automatizada utilizando GitHub Actions e cron-job.org.

**Tecnologias utilizadas**

`Python` · `GitHub Actions` · `Git` · `JSON` · `Telegram Bot API` · `cron-job.org`

**Status:** 🟢 Em operação desde novembro de 2026.

**Código-fonte:** 🔒 Privado — projeto apresentado para fins de demonstração técnica e portfólio.
